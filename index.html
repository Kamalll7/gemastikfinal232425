Cara Membaca Source Code & Menemukan Celah dalam 3 Langkah

Saat lomba Attack–Defense dimulai, jangan baca kode dari baris 1 sampai habis seperti membaca novel. Gunakan kacamata Source-to-Sink: cari dari mana input luar masuk (Source), lihat bagaimana data itu diubah/ditempel (Transform), dan temukan fungsi kritis yang mengeksekusinya (Sink).

1. SOURCE Titik Masuk Input User

Semua data yang berasal dari luar server dan bisa diubah sesuka hati oleh attacker:

  • • Flask: request.args, request.form, file.filename
  • • Go: r.URL.Query().Get(), fmt.Scanln()
  • • NestJS/TS: @Query(), @Body(), @Param()
  • • PHP/Ruby: $_POST, $_GET, params[:word]
  • • C/C++: fgets(), scanf(), cin.getline()
2. TRANSFORM Perjalanan & Penggabungan Data

Bagaimana program mengolah input tadi sebelum masuk ke fungsi berbahaya:

  • • Gabung string: f"...", fmt.Sprintf(), +
  • • Gabung path: os.path.join(), filepath.Join()
  • • Ganti isi template: .replace("{{...}}", input)
  • • Hitung angka: cost = cost + price, money -= donate
  • • Nonce/Key: int(time()) atau H(username)
3. SINK Fungsi Eksekusi Berbahaya

Titik tempat meledaknya vulnerability jika kemasukan input mentah:

  • • Shell/OS: os.system(), subprocess(shell=True)
  • • Database: db.executescript(), db.Get(sprintf)
  • • File: open(), ioutil.ReadFile(), xlsx.read()
  • • Template: render_template_string(), Slim::Template
  • • Memory C: strcpy(), fgets(buf, 200), memmove()
